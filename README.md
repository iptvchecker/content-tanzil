# Tanzil Quran text mirror

This repository preserves a verbatim copy of Tanzil Project's Uthmani Quran text, version 1.1, for reliable reuse by iQuranHolder (حامل القرآن). The Quran text and original embedded copyright notice are unchanged.

Source: [Tanzil Project](https://tanzil.net/). [Download](https://tanzil.net/download/). [Text license and conditions](https://tanzil.net/docs/Text_License). [Publisher updates](https://tanzil.net/updates/).

## Reuse conditions

The publisher permits verbatim copying and distribution and prohibits changing the text. Clearly credit Tanzil Project, link to tanzil.net and retain its original copyright notice in copies and files containing substantial portions of the text. The full publisher notice remains inside `tanzil-uthmani-1.1.txt`.

`SOURCE.json` records provenance, version, size and SHA-256. `CHECKSUMS.sha256` allows verification of the original bytes.

## Updates and retention

Fetch source updates into a separate review branch. Verify original bytes, Quran integrity, version, attribution and publisher conditions before publishing a new version. Never automatically delete a mirrored file because the original server removes it. Preserve existing immutable releases and the revisions required by installed apps. Any removal requires a deliberate maintainer decision; publisher obligations remain in force.
